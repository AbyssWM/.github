# 刀 Abyss

**A dark, minimal Wayland ecosystem – configured in code.**

</div>

---

Abyss is a fork of the [Hyprland](https://github.com/hyprwm/Hyprland) ecosystem with its own identity:

- **Abyssland** – a dynamic tiling Wayland compositor
- **Abysslang** – no config file: your config is C++ code, compiled in (like dwm's `config.h`)
- **Own libraries** – every library is forked and renamed, so system updates can never break it
- **Katana look** – deep night blue, cold steel, a touch of gold

> 🚧 **Early development.** Nothing here is ready for daily use yet.
